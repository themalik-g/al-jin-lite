🎯 Why These Are "Unpatchable"

These methods exploit the gap between what WhatsApp's server validates and what the client renders. WhatsApp's servers accept these messages because they are structurally valid protobuf messages using legitimate fields. The crash happens on the recipient's device when the client's rendering logic encounters an edge case the developers didn't anticipate.

AI Rich Response (AddonAction) is the strongest candidate. The addonActionSection is a Meta AI feature that renders interactive overlay buttons. Each item requires a label or icon. When neither is present, the client's rendering path accesses a button object that doesn't exist, causing a force-close. The GenAIFooterActionPrimitive has a cta_text and footer_action_type but is not an overlay button — placing it in addonActionSection produces a button without a label, which triggers the crash.
The QuotaUpsellSection has a similar trap: the card is discarded entirely when meter_usage_type is META_AI_THINK_HARD or benefit_type contains THINK_HARD. An empty button list is not sent as []; the field is omitted entirely.
